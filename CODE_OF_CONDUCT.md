# NovaStream Code of Conduct

## Purpose

This Code of Conduct establishes expectations for all contributors,
maintainers, staff, contractors, and community members participating
in any NovaStream project, community forum, or repository.

Our goal is to foster a professional, safe, collaborative environment
that enables constructive discussion and high-quality technical work.

---

## Expected Behavior

All participants are expected to:

- Act with professionalism, courtesy, and respect.
- Use inclusive, non-discriminatory language.
- Accept constructive feedback gracefully.
- Assume good intent while addressing issues thoughtfully.
- Prioritize safety, privacy, and security in all discussions and actions.
- Follow relevant regulatory obligations, including confidentiality
  and data protection requirements.

---

## Unacceptable Behavior

The following actions are not tolerated:

- Harassment, intimidation, or abusive communication.
- Discrimination based on race, ethnicity, nationality, religion,
  gender identity, sexual orientation, disability, or age.
- Sexual or violent language or imagery.
- Trolling, spamming, or persistent disruption of discussions.
- Public disclosure of personal, confidential, or protected data
  (including security vulnerabilities or PHIA-scoped information).
- Attempts to bypass security policies or contributor verification
  requirements.
- Coercive, manipulative, or unethical behavior of any kind.

---

## Security and Privacy

NovaStream projects operate under strict privacy and security standards.

- **Do not disclose vulnerabilities publicly.**
  All security issues must be reported via the channels documented in
  `.github/SECURITY.md`.

- **Do not post any protected personal, health, or client information**
  in GitHub issues, discussions, or pull requests.

Violations of privacy or security rules may result in immediate removal
from project participation.

---

## Enforcement

Project maintainers and NovaStream administrators have full authority
to enforce this Code of Conduct.

Enforcement actions may include:

- Warning or removal of content
- Temporary or permanent contributor bans
- Revocation of repository access
- Escalation to organizational leadership or legal review

---

## Reporting

Concerns should be reported privately:

- **Email:** <hr@novastream.ca>  
- **Security issues:** Per `.github/SECURITY.md`

Reports will be reviewed confidentially and addressed promptly.

---

## Scope

This Code of Conduct applies to:

- All NovaStream and client-owned GitHub repositories
- Issues, pull requests, code reviews, discussions, chats, and commits
- Internal, community or professional channels associated with NovaStream
  projects as well as social media
